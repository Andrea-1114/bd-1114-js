# 1.Que pasa con este codigo si necesito 5 filtros? Y si necesito 10?

 Si necesito 5 filtros, puedo seguir agregando .filter() al código, igual que ya están los 3 filtros. Si necesito 10, también se puede, pero el código quedaría más largo y puede ser más difícil de entender. Cada filtro va quitando los alumnos que no cumplen con la condición.

# 2.Si cierro el programa, donde quedaron los datos?

 Si cierro el programa, los datos no quedan guardados permanentemente. En este código, los datos están en la memoria mientras el programa está funcionando. Cuando cierro el programa, esos datos se pierden porque no se están guardando en un archivo o en una base de datos.
